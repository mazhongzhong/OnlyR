## 4. Windows 手工验收结果

以下项目已经在便携版中确认通过：

- 正常启动后显示灰色托盘图标。
- 托盘菜单包含开始、停止、暂停或继续、显示窗口、打开录音文件夹和退出。
- 开始录音后图标变红；暂停后图标变黄且菜单显示继续；停止后图标恢复灰色。
- 托盘的开始、停止、暂停和继续命令有效。
- 双击托盘图标可以恢复同一个主窗口。
- 打开录音文件夹有效。
- 托盘退出有效，退出后托盘图标消失。
- 设置页显示“点击关闭按钮时仅在托盘显示”，默认启用。
- 点击最小化按钮时执行普通最小化，任务栏按钮仍存在。
- 启用上述设置后点击 X，主窗口和任务栏按钮消失，托盘图标及录音继续存在。
- 关闭上述设置后点击 X，程序走原有真正关闭路径。
- 修改设置并重启后，设置值正确保存。
- 托盘退出在空闲和录音状态下继续遵守原有 `AllowCloseWhenRecording` 设置。
- 设置页能够列出多个麦克风；分别选择两个麦克风录音时实际使用了所选设备；重启后选择仍然保留。
