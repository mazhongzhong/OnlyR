# OnlyR <img src="https://ci.appveyor.com/api/projects/status/ap0q5inx86kofqwi?svg=true">

> **Unofficial fork:** This repository is an unofficial fork of
> [AntonyCorbett/OnlyR](https://github.com/AntonyCorbett/OnlyR). It adds Windows
> notification-area controls and close-to-tray behavior. It is not an official
> release of, or endorsed by, the original project maintainer.

Windows audio recorder using C#, WPF, NAudio, NAudio.Lame, AutoMapper, GalaSoft MvvmLight, 
Newtonsoft, Serilog. The minimal UI features a start/stop button and volume meter. 
Stores recordings in a folder hierarchy according to date.

<img src="http://cv8.org.uk/soundbox/OnlyR/Images/OnlyR04.png" alt="OnlyR"> 

### System Requirements

* Windows 10 or later
* 2GB RAM
* 15MB Hard disk space
* Audio recording device

### Download

Download the permanent portable ZIP from this fork's
[latest release](https://github.com/mazhongzhong/OnlyR/releases/latest). The
executable is currently unsigned, so Windows Defender SmartScreen may show an
"Unknown publisher" warning on first launch.

For official upstream installers and portable builds, use the
[original OnlyR releases](https://github.com/AntonyCorbett/OnlyR/releases/latest).
